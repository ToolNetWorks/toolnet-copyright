# Certificate typography

Unmodified WOFF2 files from Google Fonts CSS2 for Source Sans 3 (weights 400–700) and Source Serif 4 (400–600). Included subsets: Latin, Latin extended and Vietnamese. Files are self-hosted; runtime requests stay on this application origin.

- https://github.com/google/fonts/tree/main/ofl/sourcesans3
- https://github.com/google/fonts/tree/main/ofl/sourceserif4
- https://fonts.googleapis.com/css2?family=Source+Sans+3:wght@400..700&family=Source+Serif+4:wght@400..600&display=swap

The accompanying SIL Open Font License files apply to the fonts. Retrieved 2026-10-29. Font binaries were not edited.
